# GymTracker 🏋️‍♂️

Современное офлайн-приложение для ведения дневника тренировок в тренажёрном зале, созданное на **Jetpack Compose**, **Material 3 Expressive** и **Room**, с поддержкой синхронизации смарт-часов (OnePlus Watch 2 / OHealth) через **Android Health Connect**, конструктором планов тренировок, интерактивным справочником техники с двухкадровыми фото-анимациями из **free-exercise-db** через CDN, базой из **970+ упражнений на русском языке**, отслеживанием прогрессии и функцией резервного копирования.

---

## 🌟 Ключевые возможности

### 1. Каталог из 970+ упражнений и интерактивная база
* **Встроенная база (970+ упражнений на русском языке)**: приложение поставляется со встроенным файлом `extended_exercises.json` в `assets/`, переведённым на русский язык, с разбивкой по 6 группам мышц, типам упражнений и подробными подсказками по технике.
* **Поиск на лету при добавлении**: если нужного упражнения нет в локальном списке частых упражнений, окно поиска мгновенно находит его в полной энциклопедии и позволяет добавить в тренировку или план одним кликом (**`[+] В тренировку`** / **`[+] В план`**).
* **Импорт всей базы в один клик**: в разделе **Настройки** доступна кнопка **«Загрузить полную базу (900+ упражнений)»**, которая импортирует все упражнения в локальную базу данных SQLite Room для быстрого доступа без интернета.

### 2. Справочник техники с визуализацией из free-exercise-db (BottomSheet)
* **Интерактивная шторка техники**: выезжает снизу по нажатию на кнопку **`ℹ️`** рядом с любым упражнением в активной тренировке или плане.
* **Двухкадровые фото-анимации (free-exercise-db)**:
  * Загрузка реальных иллюстраций движения (Кадр 1: исходное положение, Кадр 2: пиковое сокращение).
  * **Режим «Сравнение фаз»**: оба кадра отображаются рядом с подписями для детального изучения углов и хвата.
  * **Режим «Анимация (1 ↔ 2)»**: зацикленное плавное переключение между фазами движения.
* **Надёжная доставка через jsDelivr CDN**:
  * Изображения загружаются через высокоскоростной глобальный CDN (`https://cdn.jsdelivr.net/gh/yuhonas/free-exercise-db@main/exercises/...`), который стабильно открывается у любых российских интернет-провайдеров и мобильных операторов (без блокировок `raw.githubusercontent.com`).
  * Для каждого изображения отображается индикатор загрузки (`CircularProgressIndicator`).
* **Офлайн-фоллбэк на векторную графику**: при отсутствии интернета или если у кастомного упражнения нет фото, шторка автоматически переключается на векторную схему движения (`Compose Canvas`) с неоновой подсветкой активных мышц.
* **Чек-лист техники**: три структурированных блока:
  1. 🟢 *Исходное положение* (стопы, лопатки, хват, настройка тренажёра).
  2. 🟢 *Движение и дыхание* (выдох на усилии, амплитуда, темп).
  3. 🔴 *Чего избегать* (типичные травмоопасные ошибки).

### 3. Программы и планы тренировок
* **Многопрограммный режим**: создавайте и ведите собственные тренировочные сплиты (*«Трёхдневный сплит»*, *«Фуллбоди»*, *«Push-Pull-Legs»*).
* **Тренировочные дни**: настраивайте дни сплита с указанием целевых мышечных групп (*День 1: Грудь и трицепс*, *День 2: Спина и бицепс*).
* **Планирование объёма**: количество подходов, целевые повторения (например, *8–10*) и целевые рабочие веса.
* **Запуск тренировки по плану**: кнопка **«Начать тренировку (День X)»** автоматически переносит все упражнения и запланированные подходы в активную сессию.
* **Удаление программ**: возможность удалить ненужную или завершённую программу через кнопку корзины с подтверждением в диалоговом окне.
* **Активная программа**: выбор программы по умолчанию для быстрого старта с главного экрана.

### 4. Запись тренировок и умный учёт веса
* **Адаптация под упражнения с собственным весом**:
  * *С отягощением* (жимы, приседания, тяги) — стандартные поля веса и повторений.
  * *Только свой вес* (отжимания от пола, пресс, гиперэкстензия) — поле веса скрыто, фокус на повторениях.
  * *Свой вес + доп. вес* (подтягивания, брусья) — переключатель **«Свой вес»** ↔ **«+ Доп. вес»** (+5 кг, +10 кг на поясе).
* **Автоматическая фиксация сетов**: введённые подходы автоматически считаются выполненными и сохраняются в историю.
* **Индикаторы прогрессии**: мгновенный расчёт дельты относительно прошлого раза (**`▲ +2.5 кг`**, **`▲ +2 повт.`**, **`▼ -5 кг`**) и подсветка личного рекорда (**🏆 Рекорд**).
* **Удобный ввод**: крупные кнопки, поддержка точки и запятой, сдвиг интерфейса при открытии клавиатуры (`imePadding`), режим бодрствования экрана (`FLAG_KEEP_SCREEN_ON`).

### 5. История и Health Connect (OnePlus Watch 2 / OHealth)
* **Детальная история**: раскрывающиеся карточки тренировок со списком всех подходов и суммарным тоннажем.
* **Синхронизация с часами**: автоматическое считывание официальных тренировок из OHealth через Health Connect либо фонового пульса и калорий за интервал занятия.
* **Метрики здоровья**: средний пульс, пиковый пульс, активные калории и кнопка ручной синхронизации **🔄**.

### 6. Статистика, рекорды и 1ПМ
* **Периоды**: день, неделя, месяц, год, всё время.
* **Показатели**: количество тренировок, непрерывная серия (🔥 стрик), максимальный 1ПМ (по формуле Эпли), максимальный рабочий подход, суммарно выполненные подходы.
* **Аналитика по группам мышц**: распределение подходов и прогресс по 6 мышечным группам.

### 7. Резервное копирование и перенос данных (JSON)
* **Экспорт / Импорт**: сохранение всех тренировок, истории, упражнений и **всех программ с планами** в стандартизированный файл `.json` через Storage Access Framework (SAF).
* **Google Auto Backup**: автоматическое шифрованное резервное копирование базы данных в личный Google Drive.

### 8. Дизайн Material 3 Expressive
* **Тёмная тема**: контрастный тёмный графит (`#0D0F13`), акцентный оранжевый (`#FF6F00`) и фиолетовый (`#BB86FC`).
* **Edge-to-Edge**: системные бары Android полностью прозрачны.
* **Навигация**: 5 основных вкладок (Главная, Планы, История, Статистика, Настройки).

## 🚀 Сборка проекта

### В облаке через GitHub Actions (Рекомендуемый способ)
1. Создайте новый репозиторий на GitHub.
2. Распакуйте архив и загрузите проект:
   ```bash
   git init
   git add .
   git commit -m "Initial commit GymTracker v2.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/gym-tracker.git
   git push -u origin main
   ```
3. Во вкладке **Actions** начнется автоматическая сборка.
4. Скачайте готовый `app-debug.apk` в разделе **Artifacts**.

### В Android Studio
1. Откройте проект в Android Studio (Hedgehog или новее) с JDK 17.
2. Дождитесь синхронизации Gradle и нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.
