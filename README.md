# GymTracker 🏋️‍♂️

Современное офлайн-приложение для ведения дневника тренировок в тренажёрном зале, созданное на **Jetpack Compose**, **Material 3 Expressive** и **Room**, с поддержкой синхронизации смарт-часов (OnePlus Watch 2 / OHealth) через **Android Health Connect**, конструктором планов тренировок, интерактивным справочником техники с двухкадровыми фото-анимациями из **free-exercise-db** через CDN, базой из **970+ упражнений на русском языке**, классификацией типов подходов, суперсетами, графиками прогрессии и функцией резервного копирования.

---

## 🌟 Ключевые возможности

### 1. Запись тренировок и умные типы подходов (Новое)
* **Классификация подходов (DropdownMenu)**:
  * Нажмите на номер сета в строке подхода, чтобы выбрать его тип из удобного меню:
    * **Обычный подход** (цифра `1`, `2`, `3`...).
    * **W — Разминочный (Warmup)**: желтовато-серый бейдж. Исключается из расчёта рекордов (1ПМ/PR) и чистого рабочего объёма.
    * **D — Дропсет (Drop-set)**: фиолетовый бейдж для подходов со сбросом веса.
    * **F — До отказа (Failure)**: кораллово-красный бейдж для контроля интенсивности.
* **Адаптация под собственный вес**:
  * *Только свой вес* (отжимания от пола, пресс, гиперэкстензия) — поле веса скрыто.
  * *Свой вес + доп. вес* (подтягивания, брусья) — переключатель **«Свой вес»** ↔ **«+ Доп. вес»** (+5 кг, +10 кг на поясе).
* **Индикаторы прогрессии**: мгновенный расчёт дельты относительно прошлого раза (**`▲ +2.5 кг`**, **`▲ +2 повт.`**, **`▼ -5 кг`**) и подсветка личного рекорда (**🏆 Рекорд**).
* **Удобный ввод**: крупные поля ввода, поддержка точки и запятой, сдвиг интерфейса при открытии клавиатуры (`imePadding`), режим бодрствования экрана (`FLAG_KEEP_SCREEN_ON`).

### 2. Суперсеты между любыми упражнениями (Новое)
* **Связывание любых упражнений**: нажмите кнопку `🔗` на карточке любого упражнения и выберите парное упражнение из списка тренировки (даже если они находятся не рядом).
* **Наглядная индикация**:
  * Связанные упражнения получают общий цветной бейдж (например, **`🔗 Суперсет A`**, **`🔗 Суперсет B`**).
  * На каждой карточке выводится имя парного упражнения (*«В связке с: Жим гантелей лёжа»*).
  * Возможность в один клик разъединить суперсет.
* **Поддержка в планах**: суперсеты можно настраивать в конструкторе программ, и они автоматически переносятся в активную тренировку при старте по плану.

### 3. Программы тренировок и изменение порядка упражнений (Новое)
* **Многопрограммный режим**: создавайте и ведите собственные тренировочные сплиты (*«3-дневный сплит»*, *«Фуллбоди»*, *«Push-Pull-Legs»*).
* **Управление очерёдностью (Drag & Drop)**:
  * На каждой карточке упражнения в дне программы доступна рукоятка **`≡`** и кнопки быстрого перемещения вверх/вниз для настройки удобной последовательности снарядов.
* **Планирование объёма**: количество подходов, целевые повторения (например, *8–12*) и целевые рабочие веса.
* **Запуск тренировки по плану**: кнопка **«Начать тренировку (День X)»** автоматически переносит все упражнения, суперсеты и запланированные подходы в активную сессию.
* **Удаление программ**: кнопка корзины с подтверждением в диалоговом окне.

### 4. Интерактивные графики прогресса (Новое)
* **Точки входа**: откройте карточку тренировки в **Истории** или блок мышечной группы в **Статистике** и нажмите на любое упражнение.
* **Линейный график прогрессии (Canvas)**:
  * Кривая расчётного разового максимума (**1ПМ по формуле Эпли**) и кривая лучшего рабочего веса по датам тренировок.
  * Интерактивные точки: тап по точке показывает дату, 1ПМ и параметры рабочего подхода.
  * Фильтры периода: **«1 мес»**, **«3 мес»**, **«6 мес»**, **«Всё время»**.
* **Абсолютные рекорды**: карточки лучшего 1ПМ и максимального рабочего сета за всё время.
* **Подробная история подходов**: список всех тренировок с этим упражнением и цветовой индикацией типов сетов (`W`, `D`, `F`).

### 5. Справочник техники с визуализацией из free-exercise-db (BottomSheet)
* **Вызов в один клик**: кнопка **`ℹ️`** доступна рядом с каждым упражнением.
* **Двухкадровые фото-анимации (`free-exercise-db`)**:
  * Исходное положение ➔ пиковое сокращение.
  * Два режима: **«Сравнение фаз»** (два фото рядом) и **«Анимация»** (зацикленный просмотр 1 ↔ 2).
* **Доставка через jsDelivr CDN**: фото загружаются через `cdn.jsdelivr.net` без блокировок и задержек у провайдеров РФ.
* **Офлайн-фоллбэк**: при отсутствии интернета или для кастомных упражнений отображается векторная схема `Canvas` с неоновой подсветкой активных мышц.
* **Чек-лист техники**: структурированные подсказки по исходному положению, дыханию и частым ошибкам.

### 6. Встроенная база на 970+ упражнений на русском языке
* **Полный каталог**: энциклопедия переведена на русский язык и упакована в приложение (`assets/extended_exercises.json`).
* **Поиск на лету**: мгновенный поиск по полной энциклопедии в диалоге добавления упражнений с кнопками `[+] В тренировку` и `[+] В план`.
* **Загрузка в локальную базу**: кнопка в Настройках «Загрузить полную базу (900+ упражнений)» для офлайн-доступа.

### 7. История и Health Connect (OnePlus Watch 2 / OHealth)
* **Раскрывающиеся карточки тренировок**: детальный просмотр каждого подхода с бейджами типов сетов и суммарного рабочего тоннажа.
* **Синхронизация с часами**: считывание тренировок, пульса и калорий из OHealth через Health Connect.
* **Резервное копирование (JSON)**: экспорт/импорт всех тренировок, упражнений, программ, суперсетов и типов сетов через SAF.

## 🚀 Сборка проекта

### В облаке через GitHub Actions (Рекомендуемый способ)
1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "GymTracker v2.1.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/gym-tracker.git
   git push -u origin main
   ```
3. Во вкладке **Actions** начнется автоматическая сборка.
4. Скачайте готовый `app-debug.apk` в разделе **Artifacts**.

### В Android Studio
1. Откройте проект в Android Studio (Hedgehog или новее) с JDK 17.
2. Дождитесь синхронизации Gradle и нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.
