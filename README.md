# GymTracker 🏋️‍♂️

Современное офлайн-приложение для ведения дневника тренировок в тренажёрном зале, созданное на **Jetpack Compose**, **Material 3 Expressive** и **Room**, с поддержкой синхронизации смарт-часов (OnePlus Watch 2 / OHealth) через **Android Health Connect**, конструктором планов тренировок, интерактивным справочником техники с векторными анимациями, отслеживанием прогрессии и функцией резервного копирования.

---

## 🌟 Ключевые возможности

### 1. Программы и планы тренировок (Новое)
* **Несколько программ**: создавайте и ведите собственные программы (например, *«Классический 3-дневный сплит»*, *«Фуллбоди»*, *«Push-Pull-Legs»*).
* **Тренировочные дни**: делите программу на дни (*День 1: Грудь и трицепс*, *День 2: Спина и бицепс* и т.д.).
* **Плановые подходы**: настраивайте количество подходов, целевой диапазон повторений (например, *8–10 повт.*) и целевой вес.
* **Быстрый старт по плану**: кнопка **«Начать тренировку (День X)»** мгновенно открывает экран записи тренировки, куда уже предзаполнены все упражнения и количество запланированных подходов.
* **Выбор активной программы**: назначьте активную программу, и она будет отображаться для быстрого перехода на главном экране.

### 2. Справочник техники и векторные анимации (Новое)
* **Скрытые подсказки по технике (BottomSheet)**: рядом с каждым упражнением в плане и во время тренировки доступна аккуратная кнопка **`ℹ️`**.
* **Двухкадровые схематичные векторные SVG-анимации**:
  * Плавное зацикленное переключение между **Кадром 1 (Исходное положение)** и **Кадром 2 (Пиковое сокращение)**.
  * Траектория движения со стрелками.
  * **Неоновая подсветка работающих мышц** (грудь, широчайшие спины, квадрицепсы, дельты, бицепс, трицепс, пресс).
  * 100% векторная отрисовка: нулевой расход памяти и чёткость на любых экранах.
* **Чек-лист правильного выполнения**:
  1. 🟢 *Исходное положение* (положение стоп, лопаток, хват).
  2. 🟢 *Движение и дыхание* (выдох на усилии, амплитуда).
  3. 🔴 *Чего избегать* (частые травмоопасные ошибки).

### 3. Запись тренировок и умный учёт веса
* **Адаптация под тип упражнения**:
  * *С отягощением* (жимы, тяги, приседания) — стандартные поля веса и повторений.
  * *Собственный вес* (отжимания от пола, гиперэкстензия, пресс) — поле веса скрыто, поле повторений центрировано.
  * *Свой вес + опция отягощения* (подтягивания, брусья) — аккуратный переключатель **«Свой вес»** ↔ **«+ Доп. вес»** (+5 кг, +10 кг на поясе).
* **Автоматическая отметка сетов**: введённые подходы автоматически считаются завершёнными и идут в статистику без обязательного прокликивания чекбоксов.
* **Индикаторы прогрессии на лету**: мгновенный бейдж дельты (**`▲ +2.5 кг`**, **`▲ +2 повт.`**, **`▼ -5 кг`**) и личного рекорда (**🏆 Рекорд**).
* **Защита от перекрытия клавиатурой**: список автоматически сдвигается наверх при открытии цифровой клавиатуры (`imePadding`).
* **Экран не гаснет**: режим `FLAG_KEEP_SCREEN_ON` активен во время выполнения подходов.

### 4. История тренировок
* **Интерактивные карточки**: разворачивание всех упражнений и подходов в один клик.
* **Сводные показатели**: дата, общее количество упражнений, реальный суммарный вес тренировки.
* **Удаление записей**: возможность удалить ошибочно сохранённую тренировку.

### 5. Интеграция со смарт-часами (OnePlus Watch 2 / OHealth)
* **Работа через Health Connect**: автоматическое считывание официальных тренировочных сессий OHealth либо фонового пульса и калорий за интервал занятия.
* **Метрики здоровья**: средний пульс, пиковый пульс и активные сожжённые калории.
* **Ручная синхронизация 🔄**: кнопка обновления данных с часов в карточке истории.

### 6. Статистика, рекорды и максимумы (1ПМ)
* **Периоды**: день, неделя, месяц, год, всё время.
* **Ключевые показатели**: количество тренировок, стрик (🔥 серия дней), **максимальный 1ПМ (за 1 повторение по формуле Эпли)**, **максимальный рабочий подход**, число сетов, калории и средний пульс.
* **Группы мышц без лишнего тоннажа**: распределение объёма по подходам и максимальный 1ПМ в каждой группе мышц.
* **Интерактивное раскрытие по группам мышц**: при нажатии на любую группу мышц разворачивается список упражнений с фиксацией максимального веса за 1 повторение (1ПМ), лучшего рабочего сета (`вес × повторения`) и числа подходов.

### 7. Резервное копирование и перенос данных (JSON)
* **Экспорт в один клик**: сохранение всех тренировок, истории, созданных упражнений и **всех программ с планами** в стандартизированный файл `.json`.
* **Восстановление**: мгновенный импорт через системный проводник Android (SAF).
* **Google Auto Backup**: автоматическое облачное резервное копирование БД в аккаунт Google.

### 8. Дизайн Material 3 Expressive
* **Цветовая палитра**: контрастный тёмный графит (`#0D0F13`), акцентный оранжевый (`#FF6F00`) и неоновый фиолетовый (`#BB86FC`).
* **Навигация**: 5 вкладок (Главная, Планы, История, Статистика, Настройки).
* **Честный Edge-to-Edge**: системная навигационная панель Android полностью прозрачна, без белых полос снизу.
* **Адаптивная векторная иконка**: неоновый логотип гантели для рабочего стола Android.

| Компонент | Технология | Описание |

| **Язык** | Kotlin 1.9.24 | Строгая типизация, корутины, StateFlow |

## 🚀 Инструкция по сборке

### Способ 1: Сборка в облаке через GitHub Actions (Рекомендуемый)
1. Откройте ваш репозиторий на [GitHub](https://github.com).
2. Замените файлы проекта на файлы из обновлённого архива или закоммитьте изменения:
   ```bash
   git add .
   git commit -m "Add Programs, Technique SVG BottomSheet, and Bodyweight exercises"
   git push origin main
   ```
3. Перейдите во вкладку **Actions** в репозитории на GitHub.
4. Процесс **Build Android APK** запустится автоматически.
5. По завершении скачайте готовый `gym-tracker-apk` с файлом `app-debug.apk` в разделе **Artifacts**.

### Способ 2: Локальная сборка в Android Studio
1. Откройте Android Studio (Hedgehog 2023.1.1 или новее) и JDK 17.
2. Выберите **File** → **Open** и укажите папку проекта.
3. Дождитесь синхронизации Gradle и нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.

## ⌚ Настройка синхронизации с OnePlus Watch 2

1. На смартфоне откройте приложение **OHealth**:
   - Перейдите в **Профиль** → **Связанные сервисы / Обмен данными** → выберите **Health Connect** и включите экспорт данных (Пульс, Тренировки, Калории).
2. В приложении **GymTracker**:
   - Перейдите на вкладку **Настройки** → нажмите **«Подключить OHealth / Health Connect»**.
   - В появившемся системном диалоге Android подтвердите доступ на чтение пульса и калорий.
3. При завершении тренировки в GymTracker данные о пульсе и сожжённых калориях будут прикрепляться автоматически. Если часы передали данные с задержкой по Bluetooth, нажмите значок **🔄 (Обновить с часов)** в карточке тренировки.
