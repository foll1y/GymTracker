# GymTracker 🏋️‍♂️

Современный и быстрый офлайн-дневник тренировок для Android на **Jetpack Compose** и **Material 3 Expressive**.
Включает умный конструктор программ, автосохранение активной тренировки, встроенный таймер отдыха, справочник техники с анимациями, базу из 970+ упражнений, аналитику прогресса (1ПМ и тоннаж) и синхронизацию со смарт-часами через **Health Connect**.

---

## ⚡ Ключевые возможности

* **🏠 Умный главный экран**: автоматическая рекомендация следующего тренировочного дня по активному сплиту, быстрый возврат к незавершённой тренировке и сводка прогресса за последние 7 дней.
* **⏱️ Таймер отдыха и секундомер тренировки**: автоматический запуск обратного отсчёта отдыха после отметки подхода (с кнопками `-15с`, `+30с`, звуковым сигналом и настройкой базового времени в настройках).
* **🛡️ Защита от потери данных (Draft Auto-Save)**: текущая тренировка автоматически сохраняется в черновик при каждом действии и восстанавливается даже после выгрузки приложения из памяти.
* **📋 Программы и сплиты**: конструктор тренировочных дней, редактирование целевых подходов/повторений/весов в один тап, переименование программ и дней, сортировка упражнений и старт тренировки в один клик.
* **🔗 Суперсеты и типы подходов (W, D, F)**: объединение упражнений в связку (A, B...) и классификация сетов — обычный, разминочный (**W**), дропсет (**D**) и до отказа (**F**). Разминка не искажает рекорды, 1ПМ и рабочий тоннаж.
* **📈 Графика, 1ПМ и тоннаж**: интерактивные Canvas-графики динамики 1ПМ и рабочих весов по датам, учёт рабочего тоннажа ($\sum \text{вес} \times \text{повторения}$), фильтры периодов и отслеживание личных рекордов (🏆 PR).
* **🎬 Справочник техники (BottomSheet)**: двухкадровые фото-анимации движения из базы *free-exercise-db* через быстрый CDN (jsDelivr), два режима (сравнение фаз и зацикленная анимация) + офлайн векторные схемы с подсветкой мышц.
* **📚 База 970+ упражнений с фильтром по инвентарю**: встроенный русскоязычный и англоязычный поиск на лету, фильтрация по группам мышц и оборудованию (штанга, гантели, блочный тренажёр, свой вес).
* **⚖️ Единицы веса (кг / lbs) и собственный вес**: сквозная поддержка килограммов и фунтов с сохранением настроек, а также адаптация полей под упражнения со своим весом и дополнительным отягощением.
* **⌚ OnePlus Watch 2 / OHealth**: интеграция с **Android Health Connect** — автоматический сбор среднего/пикового пульса и активных калорий.
* **💾 Офлайн, миграции БД и бэкапы**: безопасные миграции Room без потери данных, экспорт/импорт всей истории и программ в JSON с защитой от дубликатов.

## 🛠 Технологический стек

| Слой | Технологии |
| :--- | :--- |
| **UI** | Jetpack Compose (BOM 2024.06.00), Material 3 Expressive, Canvas Graphics |
| **Архитектура** | MVVM, Clean Architecture, Kotlin Coroutines, StateFlow |
| **База данных** | Room 2.6.1 (SQLite v6, явные миграции), SharedPreferences |

| **Здоровье** | Android Health Connect (`connect-client:1.1.0-alpha07`) |
| **Сборка** | Gradle 8.7 (Kotlin DSL), AGP 8.5.2, minSdk 26, targetSdk 34 |

## 🚀 Быстрый старт и сборка

### В облаке через GitHub Actions (Рекомендуется)
1. Загрузите обновлённые файлы проекта в ваш репозиторий на GitHub:
   ```bash
   git add .
   git commit -m "Improve GymTracker UX, fix workout saving bugs, add rest timer and draft persistence"
   git push origin main
   ```
2. Перейдите во вкладку **Actions** — сборка запустится автоматически.
3. Скачайте готовый `app-debug.apk` в разделе **Artifacts**.

### В Android Studio
Откройте проект в Android Studio (Hedgehog или новее, JDK 17) и нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.
