# GymTracker 🏋️‍♂️

Современное офлайн-приложение для ведения дневника тренировок в тренажёрном зале, созданное на **Jetpack Compose**, **Material 3 Expressive** и **Room**, с поддержкой синхронизации смарт-часов (OnePlus Watch 2 / OHealth) через **Android Health Connect**, отслеживанием прогрессии и функцией резервного копирования.

---

## 🌟 Ключевые возможности

### 1. Запись тренировок и отслеживание прогрессии
* **Мгновенный старт**: тренировка начинается в один клик с автоматической фиксацией даты и времени.
* **Удобный ввод**: крупные поля ввода веса и повторений, адаптированные для работы на тренировке (поддержка точки и запятой).
* **Автозаполнение и копирование**: новые подходы автоматически дублируют параметры предыдущего сета, а упражнения предзаполняются последними рабочими весами из истории.
* **Индикаторы прогрессии на лету**:
  * При вводе веса или повторений прямо в строке подхода мгновенно появляется бейдж дельты: **`▲ +2.5 кг`**, **`▲ +2 повт.`** или **`▼ -5 кг`**.
  * **Личный рекорд (🏆 Рекорд)**: если рабочий вес превышает рекорд за всю историю упражнения, подход подсвечивается специальным бейджем.
* **Умный каталог упражнений**:
  * База из **50+ предустановленных упражнений** по 6 группам мышц (грудь, спина, ноги, плечи, руки, пресс).
  * Поиск одновременно по названию и по группе мышц.
  * Фильтрация с помощью быстрых чипов категорий.
  * Возможность создания и сохранения собственных упражнений.
* **Удаление подходов**: быстрый крестик для удаления лишних или ошибочных сетов.
* **Защита от случайных действий**: кнопка «Завершить» блокируется, если в тренировку не добавлено ни одного упражнения.
* **Режим активной тренировки**: экран смартфона не гаснет во время выполнения упражнений (`FLAG_KEEP_SCREEN_ON`).

### 2. История и подробности
* **Интерактивные карточки**: нажмите на тренировку в списке истории, чтобы развернуть подробный список всех упражнений и подходов (номер сета, вес в кг, повторения и тоннаж).
* **Сводные показатели**: дата, общее количество упражнений, суммарный тоннаж сессии.
* **Удаление тренировок**: возможность удалить ошибочно сохранённую запись.

### 3. Интеграция со смарт-часами (OnePlus Watch 2 / OHealth)
* **Работа через Health Connect**: часам не нужно напрямую подключаться к GymTracker по Bluetooth — вы продолжаете использовать штатное приложение OHealth.
* **Двухуровневый алгоритм**:
  1. *Если включили тренировку на часах* — приложение находит официальную сессию OHealth и подтягивает её показатели.
  2. *Если забыли включить тренировку* — приложение считывает фоновый пульс и калории за интервал времени тренировки.
* **Метрики здоровья**: отображение среднего пульса, пикового пульса и сожжённых калорий прямо в карточке тренировки.
* **Ручная синхронизация 🔄**: кнопка обновления данных в карточке тренировки на случай задержки передачи по Bluetooth.

### 4. Статистика и прогрессия по группам мышц
* **Периоды**: день, неделя, месяц, год, всё время.
* **Показатели**: количество тренировок, непрерывная серия (стрик в днях 🔥), общий поднятый тоннаж, суммарно сожжённые калории и средний тренировочный пульс.
* **Прогрессия по группам мышц**: подробная сводка по каждой мышечной группе — суммарный тоннаж (кг), количество выполненных подходов и процентная доля в тренировочном объёме.

### 5. Резервное копирование и перенос данных (JSON)
* **Экспорт в один клик**: в разделе «Настройки» кнопка **«Экспорт»** создаёт стандартизированный файл резервной копии (`gym_tracker_backup_YYYY_MM_DD.json`) и позволяет сохранить его на Google Диск, отправить в Telegram (в «Избранное») или сохранить в файлы телефона.
* **Восстановление**: кнопка **«Импорт»** открывает системный проводник Android — выберите сохранённый файл, и все тренировки, подходы и созданные упражнения мгновенно восстановятся в базе данных.
* **Автоматический бэкап Android**: приложение поддерживает Google Auto Backup — база данных автоматически шифруется и сохраняется в ваш личный Google Drive.

### 6. Дизайн Material 3 Expressive
* **Цветовая палитра**: контрастный тёмный графит (`#0D0F13`), акцентный оранжевый (`#FF6F00`) и неоновый фиолетовый (`#BB86FC`).
* **Формы**: выразительные скругления карточек (24.dp) и кнопок (16–24.dp).
* **Честный Edge-to-Edge**: системная навигационная панель Android полностью прозрачна, без белых полос снизу.
* **Адаптивная векторная иконка**: неоновый логотип гантели для рабочего стола Android.

## 🚀 Инструкция по сборке

### Способ 1: Сборка в облаке через GitHub Actions (Рекомендуемый)
1. Создайте новый репозиторий на [GitHub](https://github.com).
2. Загрузите файлы проекта в репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit GymTracker"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/gym-tracker.git
   git push -u origin main
   ```
3. Перейдите во вкладку **Actions** в репозитории на GitHub.
4. Процесс **Build Android APK** запустится автоматически.
5. По завершении скачайте готовый `gym-tracker-apk` с файлом `app-debug.apk` в разделе **Artifacts**.

### Способ 2: Локальная сборка в Android Studio
1. Откройте Android Studio (Hedgehog 2023.1.1 или новее) и JDK 17.
2. Выберите **File** → **Open** и укажите папку проекта.
3. Дождитесь синхронизации Gradle и нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.

## ⌚ Настройка синхронизации с OnePlus Watch 2

1. На смартфоне откройте приложение **OHealth**:
   - Перейдите в **Профиль** → **Связанные сервисы / Обмен данными** → выберите **Health Connect** и включите экспорт данных (Пульс, Тренировки, Калории).
2. В приложении **GymTracker**:
   - Перейдите на вкладку **Настройки** → нажмите **«Подключить OHealth / Health Connect»**.
   - В появившемся системном диалоге Android подтвердите доступ на чтение пульса и калорий.
3. При завершении тренировки в GymTracker данные о пульсе и сожжённых калориях будут прикрепляться автоматически. Если часы передали данные с задержкой по Bluetooth, нажмите значок **🔄 (Обновить с часов)** в карточке тренировки.

## 💾 Резервное копирование и перенос тренировок

1. Чтобы создать резервную копию:
   - Откройте **Настройки** → блок **«Резервное копирование и перенос»** → нажмите **«Экспорт»**.
   - Выберите место сохранения или отправьте файл себе в Telegram / Google Диск.
2. Чтобы восстановить тренировки на новом телефоне:
   - Установите GymTracker на новый телефон.
   - Откройте **Настройки** → нажмите **«Импорт»** → выберите ранее сохранённый `.json` файл.
   - Все тренировки, веса, подходы и созданные упражнения мгновенно появятся в приложении.
