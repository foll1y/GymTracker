# GymTracker 🏋️‍♂️

Современный и быстрый офлайн-дневник тренировок для Android на **Jetpack Compose** и **Material 3 Expressive**. 
Включает умный конструктор программ, справочник техники с анимациями, базу из 970+ упражнений, аналитику прогресса и синхронизацию со смарт-часами через **Health Connect**.

---

## ⚡ Ключевые возможности

* **📋 Программы и сплиты**: конструктор тренировочных дней, планирование подходов/повторений/весов, Drag & Drop сортировка упражнений и старт тренировки в один клик.
* **🔗 Суперсеты**: объединение любых двух упражнений в связку (A1 + A2) с наглядными цветными метками.
* **🏷️ Типы подходов (W, D, F)**: классификация сетов через выпадающее меню — обычный, разминочный (**W**), дропсет (**D**) и до отказа (**F**). Разминка не искажает рекорды и рабочий тоннаж.
* **📈 Графика и аналитика**: интерактивные Canvas-графики динамики 1ПМ и рабочих весов по датам, фильтры периодов (1м / 3м / 6м / Всё) и отслеживание личных рекордов (🏆 PR).
* **🎬 Справочник техники (BottomSheet)**: двухкадровые фото-анимации движения из базы *free-exercise-db* через быстрый CDN (jsDelivr), два режима (сравнение фаз и зацикленная анимация) + офлайн векторные схемы с подсветкой мышц.
* **📚 База 970+ упражнений**: встроенный русскоязычный каталог с мгновенным поиском на лету и опцией полной загрузки в локальную БД.
* **⚖️ Умный учёт веса**: адаптация полей ввода под упражнения с собственным весом (отжимания, турник, брусья с доп. весом).
* **⌚ OnePlus Watch 2 / OHealth**: интеграция с **Android Health Connect** — автоматический сбор среднего/пикового пульса и активных калорий.
* **💾 Офлайн и бэкапы**: 100% приватность без регистрации, экспорт/импорт всей истории и программ в JSON через проводник Android.

## 🚀 Быстрый старт и сборка

### В облаке через GitHub Actions (Рекомендуется)
1. Создайте репозиторий на GitHub и загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial commit GymTracker"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/gym-tracker.git
   git push -u origin main
   ```
2. Перейдите во вкладку **Actions** — сборка запустится автоматически.
3. Скачайте готовый `app-debug.apk` в разделе **Artifacts**.

### В Android Studio
Откройте проект в Android Studio (Hedgehog или новее, JDK 17) и нажмите **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**.
